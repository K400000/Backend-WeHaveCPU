# WeHaveCPU - Backend Service

Backend RESTful API for **WeHaveCPU**, an IT Hardware & Computer Components E-Commerce platform. Developed as part of the **Web Services and Technologies Course (Academic Year 3)**.

---

## Project Overview
A layered-architecture backend powering an e-commerce platform specializing in computer hardware, peripherals, and DIY PC components. Handles authentication, dynamic product catalog, inventory transactions, shopping carts, simulated checkout/payment, and executive analytics.

## 🏛 System Architecture

Follows a modular **Layered Architecture (Separation of Concerns)**:
```
Routes (End-points) -> Middlewares (Auth/Validation) -> Controllers (Req/Res) -> Services (SQL & Business Logic) -> PostgreSQL
```
